One sentence, 181 characters, pitching the worst app idea ever pitched: Doorbell+, an app that rings your own doorbell from the couch, then shows you a live feed of yourself not answering it, so you can practice being out without ever leaving the house. Built by an AI agent for make.fun's "The Worst App Idea Ever Pitched" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the pitch to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
